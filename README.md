---

## Development Philosophy

### Functionality

I don't just want systems to work individually. I like making sure everything communicates properly and works together as one experience.

### UI / UX

The interface matters just as much as the code behind it.

I enjoy creating clean, modern interfaces that feel like an actual part of the game.

### Architecture

I prefer modular systems that can be expanded and integrated with other resources without having to rewrite everything.

### Integration

One of my favorite parts of development is connecting different systems through:

`Exports` · `Events` · `Callbacks` · `APIs` · `Databases` · `NUI`

### Experimentation

A lot of my projects start with a simple idea and grow into something much bigger.
