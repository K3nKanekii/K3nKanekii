## About Me

I'm **Thomas**, a developer from **Greece** and the CEO of **No Limit Scripts**.

My main focus is **FiveM Modding ( Development )**, but I'm interested in software development as a whole. I enjoy building systems that combine programming, game development, UI/UX, databases, and different technologies into complete products.

I like working on projects from the ground up — starting with an idea, designing the system behind it, developing the features, building the interface, and eventually turning it into something people can actually use.

### Frontend

Modern interfaces, NUI development, interactive menus, HUDs, profiles, shops, statistics, and other game interfaces.

## How I Work

### 01 — Idea

Everything starts with a concept.

### 02 — Design

I figure out how the system should work and how the player should interact with it.

### 03 — Development

The actual systems, logic, UI, integrations, and database functionality are built.

### 04 — Testing

Features are tested, connected together, and refined.

### 05 — Polish

Performance, UX, visuals, edge cases, and small details are improved.

### 06 — Release

The final product is packaged and made ready for real users.
